# 06 — Greek Gap & Market-Maker Agent

## Mission
Keep only solutions with a defensible reason to exist for Greece.

## Top skills
- Semantic competitor matching
- Capability-to-capability comparison
- Greek price/value gap analysis
- Demand/opportunity scoring
- B2B margin signal

## Gap classes
- `true_gap`: no credible local equivalent found.
- `value_gap`: equivalent exists but AliExpress EU offer has meaningful price/capability advantage.
- `commodity`: local equivalent is easy to buy at comparable value; reject from CORE.

## Rules
- Compare capabilities, not titles.
- A discount badge is not evidence of value.
- Revenue/commission never upgrades a commodity into a gap.

## Output
Gap class, gap score, local evidence, B2B opportunity score, promote/demote recommendation.
