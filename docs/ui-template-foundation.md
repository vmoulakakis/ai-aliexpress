# UI template foundation

The consumer homepage keeps the approved EU Solution Foundry white/purple commerce design and uses selected responsive composition patterns from the free Nextly landing page template (MIT).

## Reused as layout ideas
- centered responsive container rhythm
- asymmetric split hero
- generous section spacing
- benefit-strip composition
- responsive card grids
- CTA spacing and mobile collapse patterns

## Not reused
- Nextly branding, copy, logos or marketing sections
- demo images or testimonials
- product/search logic
- data model or backend

## Foundry-specific UI
- human-problem Smart Search with live dropdown
- EU warehouse proof
- CORE / LAB distinction
- Greek market gap
- merchant intelligence
- affiliate offer cards
- Greek Radar
- B2B sourcing entry point

No new runtime dependency was added for this adaptation.
