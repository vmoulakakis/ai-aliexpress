# Homepage UX contract

- One dominant input: describe a problem or product.
- Search starts after two characters and stays fast.
- Never show a blank page when verified LAB results exist.
- CORE ranks before LAB.
- LAB must explicitly say that the Greek market gap is still under evaluation.
- A product card must show EU warehouse country and merchant evidence.
- Discount badges appear only when current/original prices are mathematically consistent.
- Affiliate commission never changes the relevance ranking.
- The consumer sees only a few curated survivors, not marketplace-scale result lists.
